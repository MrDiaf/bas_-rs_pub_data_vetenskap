Lär dig ett språk.
Förstå alla.

Variabler, villkor, loopar, funktioner, arrayer. Samma mönster finns i varje språk du kommer att möta. I C ser du dessutom hur datorn faktiskt jobbar: minne, pekare, bytes.

// räkna grannar runt cellen (x, y)
for (int dy = -1; dy <= 1; dy++)
  for (int dx = -1; dx <= 1; dx++)
    if (dx || dy)
      n += grid[(y+dy+H)%H][(x+dx+W)%W];
# räkna grannar runt cellen (x, y)
for dy in (-1, 0, 1):
    for dx in (-1, 0, 1):
        if dx or dy:
            n += grid[(y+dy) % H][(x+dx) % W]
// räkna grannar runt cellen (x, y)
for (int dy = -1; dy <= 1; dy++)
  for (int dx = -1; dx <= 1; dx++)
    if (dx != 0 || dy != 0)
      n += grid[(y+dy+H)%H][(x+dx+W)%W];
